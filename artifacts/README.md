
# Model Artifacts

This directory is reserved for locally generated model files, evaluation outputs, and related metadata.

## Guidelines

- Do not commit trained model binaries or large generated artifacts by default.
- Keep model and rule version metadata traceable to reproducible evaluations.
- Document how an artifact was produced before using it in the application.
- Never store credentials, private transaction records, or other sensitive data here.

Generated artifacts are excluded from version control unless explicitly permitted.
